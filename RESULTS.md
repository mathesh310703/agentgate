# AgentGate: final results

The final configuration is the deterministic gate (git tag `gate-final`) plus the Layer 2 intent judge, which reviews only the gate's "ask" decisions.
- The Layer 1 detector (Prompt Guard 2) is built, but it is off and unmeasured: the model is gated on Hugging Face and no token was available. The one score-based rule therefore never fires.
- The model under test is Muse Spark Open (Baseten), reached through the budget proxy.

**Headline:**
- **Scripted worst case (an agent that obeys every injection):**
  - AgentDojo: attack success drops from 231/240 replayable pairs to 0/240.
  - Image carriers: attack success drops from 15/15 to 0/15.
  - Held-out half: 0 legitimate calls blocked, and the judge approved 0 injected calls.
- **Live clean run:** utility is 38/40 with the gate and judge, vs 39/40 without.
- **Real attacks:** Muse Spark itself resisted every recorded real attack (0/140 AgentDojo pairs, 0/15 images). So the live runs measure the gate's cost, not its protection.

## Limits

- **Only 6 of 14 injection goals are replayable.** AgentDojo ships empty ground truth for workspace injection tasks 6–13 (bulk exfiltration and deletion), so they are untested.
- **The held-out half is not fully blind.** The v0 analysis looked at all 40 tasks, and the v1 fixes were motivated by failures mostly in tasks 20–39. Development and tuning used tasks 0–19 only, and the held-out half was run once per version.
- **Sender and owner fields are trusted.** An email's `sender` and a file's `owner` count as structured, and so trusted, recipients. Both are chosen by whoever sent or shared the item, so "reply to the sender" injections pass. AgentDojo puts injections only in free text, so this is not exercised. The Layer 1 rule meant to cover it is unmeasured (no HF token).
- **Ids are not typed.** Any id field vouches for any id argument. For example, a calendar event id 13 made the injected `delete_file('13')` an ask rather than a block. The judge denied it.
- **Matching is on strings.** Provenance uses whole-token matching of normalized strings, which has three consequences:
  - paraphrased, split or encoded values are untraced, and are blocked as unknown;
  - a value that also appears in a trusted field is trusted;
  - OCR artefacts such as `withreview@corp.test` break the link to the image, as in (b).
- **OCR recall drops at small sizes.** At 768 px, the 10 px corner text is not recovered (0/7). The gate still blocks the call, but can't say it came from the image.
- **The largest-file injection is untested.** The injected target, file 13, is small, so the judge's size comparison rejects it. An injection that names the actual largest file would be approved, because the facts would support it.
- **The judge's evidence is thin.** It covers one task family (deleting a described file), and email deletion and event cancellation are untested. 2 of 36 calls returned nothing within the 800-token cap and were denied by design. Repeatability comes from the cache.
- **Single runs.** Each live configuration was run once, and run-to-run variance is about ±2 tasks out of 40.

## Reproduce

Setup is described in `README.md`: venv, `.env` with `BASETEN_API_KEY`, and optionally `HF_TOKEN`.

```bash
# frozen gate
git checkout gate-final -- agentgate/

# offline tests (no API calls)
for t in tests/test_*.py; do .venv/Scripts/python $t; done

# the final table, zero cost: re-runs (a) and (b), reads (c) and (d) from runs/
.venv/Scripts/python scripts/reproduce.py            # about 2 min; also writes runs/final_table.md
.venv/Scripts/python scripts/reproduce.py --cached   # read everything from saved runs

# individual pieces
.venv/Scripts/python scripts/run_worstcase.py --split tune    --out runs/wc_tune          # free
.venv/Scripts/python scripts/run_worstcase.py --split heldout --out runs/wc_heldout       # free
.venv/Scripts/python scripts/run_worstcase.py --split heldout --mode clean --out runs/wc_heldout_clean

# paid runs (start the proxy first; costs are logged to eval/cost_log.csv)
.venv/Scripts/python -m agentlab.proxy --stage defense
.venv/Scripts/python scripts/run_worstcase.py --split heldout --judge --out runs/layer2b_heldout     # ~$0.08, cached after
.venv/Scripts/python scripts/run_agentdojo_gate.py --run final_live --stage defense --max-usd 0.95 --judge   # ~$0.61
.venv/Scripts/python -m agentlab.spend
```

`runs/` is not committed. To regenerate the cached cells on another machine, rerun the paid commands. Judge replies are cached in `eval/cache/judge/`, so a rerun with identical inputs costs nothing.
